Godot export stub:\n\nThis stub shows a minimal Godot project layout to export a hole prototype. To implement full export, generate a project folder structure:\n- project.godot\n- scenes/\n  - main.tscn (Node2D)\n  - hole.tscn (Area2D)\n- scripts/\n  - main.gd\n  - hole.gd\n- assets/ (copy sprite.svg or converted png, audio)\n\nThe exporter should map the parsed spec -> node properties (colors, speeds, target area) and zip the folder for download.
